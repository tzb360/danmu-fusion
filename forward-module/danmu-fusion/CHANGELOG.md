# Changelog

## 1.5.2 - 2026-10-26

- 修复多 API 快结果列表与宿主缓存使原生聚合入口不可见的情况：从既有有界查找元数据补入尚未过期、作品/版本/来源指纹一致的原生聚合候选，新响应优先，不等待悬挂 API。
- 原生聚合及已经验证的跨 API 分集聚合统一显示「聚合」，保留动态平台组合和真实 ID；单源与仅统一选源的入口不误标。
- 平台由实际服务器配置、作品和集数决定，没有将腾讯、爱奇艺、爱一帆或其他任意组合写死；不改服务器和弹幕内容。
- 新增 8 项聚合显示/跨 VM/失效隔离回归；实际 API 1、macOS Rex 与 AWS 日志联合验证见 TEST_REPORT_1.5.2.md。

## 1.5.1 - 2026-10-26

- 记忆成功加载的作品来源，同剧后续集和电影优先推荐；按身份、类型、年份、季数、版本与语言隔离，接口凭据变化后失效，不增加设置。
- 补充中文错误分类和安全诊断摘要，区分认证、404、5xx、网络、原生超时、格式及无结果；不输出原始异常、地址或认证信息，拒绝信任外部伪造的安全错误标记。
- 独立来源失败时依次尝试最多两个经过同作品/集数/片长/视频指纹验证的备用，不合并、不改内容与时间轴，保留原始错误；有效空进度窗口不触发切换。
- 可缓存轨道一次校验并建立分钟索引，合并并发重复加载和解析，超大轨道提前跳过缓存估算，输出副本保护缓存；及时释放首批响应等待状态中的大数据。
- 保留 1～3 API、原配置键与模块 ID、withRelated、真实 ID 路由、保守聚合、50 万条/6400 万字符整轨边界及有界缓存。
- 新增 18 项版本回归、固定 1.5.0 构建和可重复耗时/请求/资源对照；完整结果与未验证范围见 TEST_REPORT_1.5.1.md。

## 1.5.0 - 2026-10-26

- 增加 API 2/3 可选地址，API 1 保留 danmu_api_url；沿用模块 ID 与现有稳定协议流程。
- 三个 API 独立规范化、去重、并发搜索和故障隔离；优先返回已有结果，慢来源不阻塞健康来源。
- 用 SHA-256 来源指纹和真实协议 ID 构成可恢复选择；支持仅 commentId、运行时重建和来源重排，配置变化时拒绝猜测历史路由。
- 同作品详情提供独立来源；明确同版本、同季集、同片长及同视频指纹时提供安全跨 API 聚合。
- 保留原生 withRelated 聚合和保守去重，仅精确上游记录重放可跨 API 去重；不改时间轴，聚合 cid 在进度回调中保持稳定。
- 保留缓存及 50 万条容量边界；修复并行写入查找表的索引竞态，认证查询编码和新缓存键 Token 保护。
- 新增通过正式 WidgetMetadata 入口的 34 项多 API 回归、真实三地址测试脚本和延迟对比；详见 MULTI_API_TEST_REPORT_1.5.0.md。

## 1.4.5 - 2026-10-25

- 在同名不同年份的候选确需消歧时，使用标准 POST match 的 filename-only 模式辅助复核；没有虚构 year 请求字段。
- 不信任单独 isMatched 标记，复核真实资源 ID、片名、年份、类型和集数；服务端错误返回第一季时仍拒绝采纳。
- 后续季不使用系列首播年冒充当前季年份；缺乏 airDate 等可靠依据时跳过额外匹配。
- 不支持 match 或网络/JSON 异常时保留标准搜索结果；不改变真实 ID 选集及评论入口，不二次应用 shift，原生多源资源优先。
- 新增 8 项年份辅助回归，并修复数字电影名（如 2001太空漫游）的年份识别边界。

## 1.4.4 - 2026-10-25

- 修复 Rex 手动搜索 title 被 seriesName 覆盖；排除已知错误剧名、季数、类型及纪录片、解说候选，避免播放器自动探索时加载错误资源。
- 服务端原生合并覆盖所有已启用且能可靠匹配的原生来源，生产 1.21.7 增加严格剧名、年份、类型、季集保护层。
- 支持超过 20 万条的合法聚合电影响应，新增 22 万条完整轨道回归，不抽样或修改时间轴。
- 新增真实多源标签统计和进度复测脚本，保留标准单来源协议和一个 API 地址配置。

## 1.4.3 - 2026-10-25（中间验证版）
