# Danmu Fusion 1.5.1

这次更新让连续看剧时更容易找到上次用过的来源，也减少大弹幕轨道加载和拖动进度时的重复处理。设置仍只有 API 1、API 2、API 3 三个地址输入框。

## 新增与体验改进

- **记住作品来源**：成功加载某个独立来源后，同作品后续集数优先推荐该 API，电影也支持。换季、年份、身份、剪辑版、语言或接口凭据变化后重新验证；推荐不复用上一集编号，也不放宽匹配规则。
- **更清楚的中文提示**：区分地址错误、401/403 认证、404 地址、5xx 服务器故障、网络、原生超时、格式异常、无搜索结果、当前集无弹幕、绑定失效和安全证据不足。使用播放器模块日志提供安全诊断摘要，不记录私人地址、Token、认证头或原始异常。
- **可靠备用切换**：当前独立来源不可用时，只尝试已经证实同作品、同集、同片长和同视频版本的备用，最多两个、各试一次，保留原始错误。没有充分证据时继续独立选源；切换不会合并来源或改变弹幕内容、时间、颜色和位置。
- **减少重复处理**：相同在途请求共享轨道准备；可缓存轨道只校验一次并建立分钟索引；超大轨道提前跳过缓存大小估算，返回副本保护缓存，首批响应及时释放临时等待状态。

## 修复与兼容

补齐来源记忆的年份/身份隔离，防止备用详情先到导致所选主来源列表为空；不把有效空进度窗口当成来源故障，不相信外部伪造的安全异常标记或服务端诊断字段。

保留 1～3 API、原 `danmu_api_url`、模块 ID `tzb360.danmu.fusion`、1.4.5 以来的搜索/年份辅助匹配/选集/评论流程、原生 `withRelated`、来源指纹及真实 ID 路由、安全聚合和拒绝无依据合并的机制。继续采用 AGPL-3.0-only，保留作者 tzb360 与上游 danmu_api 署名。

## 验证结果

- 完整回归 **236/236**，另两份身份脚本通过；其中原生适配 29/29、多 API 34/34、新增 1.5.1 回归 18/18，均已包含在完整数量中。
- `npm ci`、正式构建、生成一致性及 JavaScript 语法检查通过。Widget VM 不提供 fetch、URL、setTimeout、AbortController、Buffer 或 Node API。
- 三个真实 API 已分别完成搜索、选集和仅 commentId 弹幕加载；macOS Rex 1.0.2 实际完成本地模块升级、API 2 弹幕显示、约十分钟进度跳转和最终构建续播。
- 性能为 Apple M2 / Node v24.19.0 / 独立 Widget VM / 固定 Mock JSON、三次中位数：220001 条首次加载 **825.17 → 529.36 ms**；4000 条轨道 80 次跳转 **644.40 → 81.03 ms**；12 个并发窗口 **187.62 → 25.85 ms**。必要 HTTP 请求数保持 **4/1/2**，多余重复请求均为 0。
- 80 次跳转场景观察堆占用 **23.74 → 11.58 MiB**；并发窗口 **25.59 → 10.54 MiB**。大轨道/连续切集的部分临时堆采样有所上升，完整资源与耗时结果见测试报告。**这些不是 iPhone 性能数据，也不是严格的分配峰值。**

## 已知限制与未验证范围

- 原版 Forward、iOS/iPhone/iPad 真实设备、长时间连续多集及手机大轨道内存：**未验证**。
- 真实跨 API 备用切换/安全合并：**未验证**；当前线上样本没有充分时间轴证据，正反例通过确定性测试。Rex 的全部记忆 UI 与故障切换分支尚未逐项实机验收。
- 备用切换必须等当前请求实际失败；全部原生请求悬挂时，等待上限仍取决于宿主超时/取消能力，未伪造客户端定时器。
- 缓存仍为最多 4 条、约 2 MiB、3 分钟，整轨边界 50 万条/6400 万字符；超大轨道不缓存，因此后续独立跳转仍可能重取整轨，不静默截断弹幕。计入对象和索引开销后，部分临界轨道更早跳过缓存。
- 未完成的慢 API 不保证加入首次列表或本轮备用，宿主列表缓存可能需重新搜索/会话；额外 message/diagnostics 字段是否显示取决于播放器，中文模块日志可用于反馈。
