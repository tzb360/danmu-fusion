# Forward 弹幕模块

[Danmu Fusion · 弹幕融合 1.5.3](./danmu-fusion/README.md) 支持 1～3 个弹幕 API，选择界面只提供聚合项，并按当前集展示「平台A&平台B&…」。平台随作品和集数动态变化，不固定为某三个平台。

导入 [完整 JS 模块](./danmu-fusion/danmu-fusion.js) 或 [安装索引](./danmu-fusion/widget.fwd)。更新同 ID 模块即可保留 API 配置；升级后重新搜索弹幕，播放器保留旧列表时请使用其实际支持的缓存刷新方式。

服务端严格保护层使用明确集号的并集：某个主平台缺集时继续聚合其余已确认来源；只剩一个平台时明确标注，不另列单平台选择项。跨 API 必须另行通过同集同版本验证，不能仅按名称或数组位置拼接。

首次搜索包含当前集平台核对，可能增加等待；超大轨道不缓存，播放时可能再次下载。功能边界及部署说明见 [模块文档](./danmu-fusion/README.md)，实际验证见 [1.5.3 测试报告](./danmu-fusion/TEST_REPORT_1.5.3.md)。
